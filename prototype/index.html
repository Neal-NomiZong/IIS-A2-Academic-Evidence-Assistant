4. V0.7 status and boundaries

Implemented: V0.4 demo interface and local controls; real OpenAlex search; backend re-fetch by selected paper ID; optional real LLM abstract screening; automated literal checks of model-proposed evidence quotations against the backend-fetched abstract.
